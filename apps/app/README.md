# BODHA trainer (`apps/app`)

Individual learning MVP: sign in, run shelf/cache exercises, chat with a server-side Mastra agent, revisit evidence-grounded reports.

See [`../../docs/bodha-mvp.md`](../../docs/bodha-mvp.md) for setup, schema, BYOK, and exercise authoring.

```bash
# from repo root
npm install
cp apps/app/.env.example apps/app/.env.local
npm run dev --workspace=app
```
